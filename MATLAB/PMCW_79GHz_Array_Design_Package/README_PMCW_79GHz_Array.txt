PMCW/FMCW 79 GHz canted 64Tx/64Rx antenna array package
=======================================================

Files:
- PMCW_79GHz_Array_Design_LiveScript_Source.m
  MATLAB sectioned source intended for the Live Editor. Run this first.

- make_mlx_in_matlab.m
  Run inside MATLAB to convert the .m source into PMCW_79GHz_Array_Design.mlx.
  This environment cannot execute MATLAB, so the binary .mlx must be generated
  by MATLAB itself.

Generated by the script when run in MATLAB:
- radarAntennaUpdate_79GHz.mat
  Struct with the frequency, power, gains, beamwidths, patch dimensions, feed
  losses, and system temperature values to integrate into your radar code.

Design summary:
- Center frequency: 79 GHz.
- Substrate assumption: RT/duroid 5880-class, er=2.2, h=0.127 mm.
- Patch first-pass dimensions: W~1.50 mm, L~1.20 mm, inset~0.42 mm.
- Aperture: 150 mm x 150 mm max projected area.
- Four 75 mm x 75 mm panels canted by 10 degrees in a pyramid-like arrangement.
- 64 Tx RF channels and 64 Rx RF channels.
- Each RF channel feeds a fixed weighted 4x4 parallel-fed patch tile.
- Total radiating patches: 1024 Tx + 1024 Rx.
- Includes EBG/metamaterial fence first-pass dimensions and 3D visualization.

Important:
This is a serious preliminary array synthesis and array-factor simulation, not a
manufacturing-ready millimeter-wave PCB. Validate the patch, inset, feed network,
EBG cell, panel seams, connectors, transitions, and Tx/Rx isolation with full-wave
EM simulation and measurement.
